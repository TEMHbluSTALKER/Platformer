# Полярная экспедиция — платформер на JavaScript

Практическое задание № 3. Двухуровневая браузерная игра «Сбор ледяных артефактов» без библиотек, игрового движка, npm и сборки. Графика целиком рисуется средствами Canvas.

## Цель игры

Пройдите **два уровня**. На каждом нужно преодолеть пять ледяных платформ, собрать три светящихся кристалла и войти в дверь полярной базы. Всего за экспедицию собирается **6 кристаллов**. Падение в ледяную воду или касание красных разломов приводит к поражению. До сбора всех трёх кристаллов текущего уровня финиш заблокирован.

1. **Уровень 1 — «Ледяной маршрут».** Северное сияние, ледяные платформы, один красный разлом и промежуточная станция.
2. **Уровень 2 — «Сквозь снежную бурю».** Иная последовательность платформ, фиолетовые оттенки неба, два разлома и финальная база.

После прохождения первого уровня игра приостанавливается и предлагает **кликабельную кнопку «Следующий уровень» прямо в центральном окне**. Очки и время сохраняются между уровнями. Если игрок погиб на втором уровне, кнопка **«Повторить уровень»** начинает второй уровень заново и возвращает значения очков и времени к моменту его начала. Кнопка **«Заново»** всегда запускает всю экспедицию с первого уровня.

## Запуск

Игра использует ES-модули. Поэтому **её нужно открывать через локальный веб-сервер**, а не двойным нажатием на `index.html` (при открытии из `file://` браузер может запретить импорт модулей).

**Для Windows:** если Python установлен, можно просто запустить файл `START_WINDOWS.bat` — он поднимет локальный сервер и откроет страницу игры в браузере. Оставьте окно сервера открытым на время игры.

**Способ 1 — Python (без дополнительных библиотек):**

1. Откройте терминал в папке проекта `Polar_Expedition`.
2. Выполните `python -m http.server 8000` (в Windows также можно `py -m http.server 8000`).
3. Откройте `http://localhost:8000`.

**Способ 2 — Visual Studio Code:** откройте папку и запустите `index.html` через расширение Live Server.

Работает в современных браузерах на компьютере и телефоне. Для открытия на телефоне через Wi-Fi нужно подключиться к локальному серверу компьютера в одной сети (с учётом настроек брандмауэра).

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Влево | Стрелка влево / A | Кнопка ← |
| Вправо | Стрелка вправо / D | Кнопка → |
| Прыжок | Пробел / W / Стрелка вверх | Кнопка ↑ |
| Пауза / продолжить | Esc / P | Кнопка под игрой |
| Начать / заново | Кнопки под игрой | Те же кнопки |

Анимированное окно приветствия содержит настоящую кнопку **«Начать игру»**. В этом же окне работают кнопки **«Продолжить»**, **«Следующий уровень»**, **«Повторить уровень»** и **«Играть снова»**, соответствующие текущему состоянию игры. Аналогичные основные кнопки под игровым полем сохранены.

Прыжок разрешён только при контакте с платформой. На телефоне экранные стрелки поддерживают удержание. При скрытии вкладки игра автоматически ставится на паузу.

## Начисление очков

Каждый кристалл приносит **100 очков**. За завершение каждого уровня начисляется **250 очков**. После прохождения обоих уровней начисляется дополнительный бонус за скорость: `max(0, round(700 − общее_время_в_секундах × 10))`. Рекорд относится к **полной экспедиции из двух уровней** и сохраняется в `localStorage` браузера, если это разрешено настройками. Рекорд однокарточной предыдущей версии не смешивается с результатами новой.

## Структура

- `index.html` — страница, игровое поле, панель счёта, кнопки.
- `START_WINDOWS.bat` — автоматический локальный запуск на Windows (при установленном Python).
- `style.css` — оформление, адаптация под телефон.
- `main.js` — создание игры, обновление интерфейса, действия кнопок.
- `Game.js` — данные двух уровней, их переходы, игровой цикл `requestAnimationFrame`, правила, рисование, рекорд.
- `Player.js` — управление, физика, гравитация, столкновения.
- `input.js` — клавиатура и сенсорные кнопки.
- `collision.js` — проверки геометрических пересечений.

## Что реализовано

- Два проходимых уровня, по пять промежуточных платформ на каждом.
- По три предмета на уровень (всего шесть), однократный подбор, общий счёт, промежуточный финиш и финальная победа.
- Переход между уровнями, повтор текущего уровня после поражения и полный перезапуск.
- Столкновения сверху, сбоку, снизу; прыжок только с опоры.
- Гравитация и движение с `dt` в секундах, защита от длинного кадра.
- Один `requestAnimationFrame`-цикл независимо от числа рестартов.
- Анимированное приветствие и настоящая интерактивная кнопка, меняющая действие в зависимости от состояния игры.
- Старт, пауза, продолжение, рестарт, автопауза при скрытии вкладки.
- Рекорд в `localStorage` с обработкой запрета доступа.
- Экранные кнопки с поддержкой удержания; адаптивное оформление.
- Без сторонних изображений и звуков (вопросы лицензий и отключения звука не возникают).

## Проверка перед сдачей

1. Запустите игру, соберите три кристалла и дойдите до первой станции — должна появиться кнопка «Следующий уровень», а не финальная победа.
2. Нажмите «Следующий уровень», соберите ещё три кристалла и дойдите до финальной базы — должна появиться победа.
3. Коснитесь разлома или упадите в воду — должно появиться поражение. На втором уровне проверьте, что «Повторить уровень» не возвращает к первому.
4. Нажмите паузу, затем продолжить; проверьте, что время не идёт в паузе.
5. Сделайте 5 рестартов подряд, проверьте скорость и отсутствие «ускорения».
6. Переключитесь на другую вкладку — должна включиться пауза.
7. Повторно откройте страницу после победы — рекорд должен сохраниться (если браузер разрешает localStorage).
8. Проверьте клики по центральной анимированной кнопке на всех экранах: старт, пауза, переход, поражение, победа.
9. На телефоне проверьте удержание кнопок ←, → и прыжок.

Для сдачи по заданию разместите папку проекта в репозитории GitHub и опубликуйте игру, например на GitHub Pages. Включите ссылки на репозиторий и работающую страницу в отчёт.
